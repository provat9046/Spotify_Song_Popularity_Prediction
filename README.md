Spotify Song Popularity Prediction Using Machine Learning

1. Introduction

This project uses Machine Learning to predict Spotify song popularity categories based on audio features.

2. Objectives

- Analyze Spotify song data.
- Perform data cleaning and preprocessing.
- Explore audio features using visualization.
- Train and compare classification models.
- Predict song popularity categories.

3. Dataset

The dataset contains Spotify song information and audio features.

After removing duplicate records, the dataset contains 1,941 records.

4. Popularity Categories

- 0–39: Not Popular
- 40–69: Moderately Popular
- 70–100: Popular

5. Technologies Used

- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

6. Machine Learning Algorithms

1. Logistic Regression
2. Decision Tree
3. Random Forest

7. Model Accuracy

Model| Accuracy
Logistic Regression| 51.41%
Decision Tree| 49.36%
Random Forest| 50.13%

8. Conclusion

The project demonstrates data preprocessing, exploratory data analysis, machine learning classification, model evaluation, and song popularity prediction.
